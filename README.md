# Макет страницы помощи Ярославу

Адаптивная вёрстка по предоставленному PDF-макету.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере либо запустите локальный сервер (например, расширение Live Server в VS Code).

## Структура
- `index.html` — разметка страницы и текст истории.
- `style.css` — стили, адаптивность для мобильных устройств.
- `script.js` — переключение фотографий и базовая проверка суммы пожертвования.
- `assets/` — фотографии, извлечённые из PDF.

## Важно
Форма пожертвования демонстрационная: она проверяет сумму и показывает сообщение, но не списывает деньги и не отправляет данные. Для реального сбора нужно подключить платёжный шлюз и серверный обработчик фонда. Ссылки на оферту и политику необходимо заменить на реальные документы.
